# Start Here

Do NOT merge existing repositories yet.

1. Put/copy candidate repositories into `11_ARCHIVE/Old_Repositories/` or another isolated workspace.
2. Build a repository inventory.
3. Audit and classify every repository as KEEP/MERGE/REWRITE/ARCHIVE/REJECT.
4. Select one small, useful component for the first integration.
5. Run it in the sandbox.
6. Add tests and observability.
7. Only then expand KAIRO agents and automation.

This repository is a foundation scaffold, not a finished autonomous AI.
