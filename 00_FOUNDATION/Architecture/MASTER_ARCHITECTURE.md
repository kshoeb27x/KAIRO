# KAIRO Master Architecture

## Layers
1. Foundation
2. Core AI
3. Agents
4. Data
5. Tools
6. Development
7. Security
8. KAIRO OS
9. Business
10. Infrastructure
11. Documentation/Archive

## Control principle
Agents may autonomously perform approved, reversible, low-risk work. Policy enforcement remains outside the model. Critical actions use least privilege, audit logs, sandboxing, rollback and explicit approval where required.

## Repository integration
Existing repositories are treated as candidates, not automatically trusted modules. Every candidate must pass inventory, dependency, license, security, functionality and duplication review before integration.
